# 公开发布边界

这是从硬件工程、App 工程和服务工程按文件白名单整理的独立快照，首次发布不继承本机工作目录的 Git 历史。

包含：项目源码、测试源码、依赖清单、SDK 集成补丁、设计素材、原生 UI 演示图和运行说明。

排除：API Key、Wi-Fi 密码、设备授权、DPAPI 文件、数据库、用户记录、串口日志、音频采集、Flash 备份、固件二进制、编译缓存、第三方完整 SDK 和字体字库。

与原工作目录相比，本次整理仅增加公开文档 / CI / 依赖获取脚本，移除本机运维材料，并将 Wi-Fi 测试网络名称替换成同长度虚构名称。公开副本的变更不会自动同步回其他正在进行的开发或板测任务。

今后更新时，先检查差异、重新执行相关测试和凭据扫描，再明确提交需要公开的文件。不要把整个原工作目录、SDK 或 Flash 备份拖入仓库。
